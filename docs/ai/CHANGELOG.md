# CHANGELOG — изменения пользовательского поведения

Формат: дата, что изменилось для пользователя.

## 2026-08-25

- Создан проект (greenfield): ядро портала (config, database, module registry, health endpoint) и доменное ядро библиотеки (канонические сущности Work/Author/Series/SourceRecord/Asset, миграция, репозитории).
- Пользовательского UI пока нет; API: `GET /healthz`, `GET /library/` (заглушка).

## 2026-08-25 (сессия 2)

- Появилась единая авторизация портала: страница входа, регистрация первого владельца (bootstrap), защищённая страница библиотеки, выход.
- API: /auth/register|login|refresh|logout|me|tokens (device-токены для будущих читалок).
- Все чувствительные действия пишутся в audit_log; login/register ограничены rate limit'ом.

## 2026-08-25 (сессия 3)

- Импорт книг: загрузка FB2/EPUB через веб (до 50 МБ, до 20 файлов за раз) и импорт из явно настроенных локальных каталогов (сначала dry-run, потом apply).
- Каталог: страница со списком произведений (авторы, циклы) и карточка произведения с файлами.
- Страница импорта: загрузка, скан каталогов, список «требуют разбора», дубликаты и кандидаты в дубликаты.
- Дубликаты по содержимому не сохраняются повторно; совпадения work+формат фиксируются как кандидаты на разбор.

## 2026-08-25 (сессия 4)

- Нормализация книг (FB2/EPUB, профиль prose_compact): кнопка «Нормализовать» у оригинального файла произведения; фоновая обработка воркером.
- Гарантия неизменности текста: отпечатки видимого текста до/после проверяются на каждом прогоне; расхождение = ошибка прогона, производный файл не создаётся.
- Внутренние иллюстрации удаляются, остаётся ровно одна обложка (оптимизируется до 1600px); неоднозначная обложка уходит на разбор.
- Страница «Нормализация»: прогоны, статусы, отчёт с действиями и отпечатками; кнопки «Сделать основным» и «Скачать».
- Скачивание файлов с человекочитаемым именем (Автор — Серия NN — Название.ext).
- Разбор импорта: несопоставленные файлы привязываются к произведению вручную; кандидаты в дубликаты разрешаются («Дубликат»/«Разные»).

## 2026-08-25 (сессия 5)

- Кнопка «Разобрать с LLM» для файлов с нестандартными именами: предложение (автор/название/цикл/номер) с правкой перед применением.
- Без настроенного AI-ключа система продолжает работать: ручная форма разбора (проверено).
- Повторный разбор одинаковых файлов не тратит вызовы модели (кэш предложений).
- Подтверждено: ключ из мастер-промпта невалиден для chat completions — нужен новый.

## 2026-08-25 (сессия 6)

- Главная страница библиотеки: «Продолжить чтение», «Дальше в циклах», «Недавно добавленные».
- Страницы циклов: таймлайн книг со статусами, следующая книга цикла, пропущенные номера, массовая отметка «прочитано», ручной статус цикла (пауза/завершён/брошен).
- Очередь чтения: что читать следующим — сначала активные циклы, потом новые.
- Быстрые действия у каждой книги: начал читать / прочитана / пауза / бросил / в очередь + история изменений.
- «Отметить прочитанной» теперь работает прямо из статуса «не прочитана» (главная мобильная кнопка).

## 2026-08-26 (сессия 13)

- **Настройки**: страница /library/settings — смена пароля (текущий → новый, мин. 12 символов). После смены все веб-сессии деавторизуются, токены FBReader остаются.
- **ZIP-импорт**: ZIP-архивы (не EPUB) автоматически распаковываются — каждый FB2/EPUB внутри становится отдельным импорт-айтемом. Архив без книг → отклонённый айтем.
- **Безопасность**: logout теперь защищён CSRF-токеном (раньше — дыра). CSRF double-submit теперь принимает токен из form-field (для SSR форм) помимо заголовка.
- Корень сайта `/` теперь перенаправляет на `/library/` (был 404 JSON).
- На всех страницах в шапке видны ссылки «Настройки» и «Выйти».
