# MCP Inventory

MCP-серверы проекта. Принцип: только там, где дают преимущество над локальными CLI (мастер-промпт §17).

| MCP | Статус | Назначение | Версия | Примечание |
|-----|--------|------------|--------|------------|
| (нет подключённых) | — | — | — | Используются: встроенные инструменты агента, `rg`, `git`, `gh`, `docker` |

## Решения

- Semantic code MCP (CodeGraph/Serena) не обнаружены на машине; используется `rg` + чтение файлов. Пересмотреть при росте кодовой базы.
- GitHub MCP не требуется: достаточно `gh` CLI (авторизация уже настроена).
- Playwright MCP: рассмотреть при Phase 8 (визуальная диагностика), E2E остаются обычными тестами.
