# ADR-0026: Author candidate review boundary

Статус: accepted
Дата: 2026-09-04

## Контекст

ADR-0025 разрешил вручную подключённой странице Author.Today автоматически
создавать canonical Author, SourceEndpoint и WatchRule для каждого соавтора со
stable profile identity. На реальном каталоге это преждевременно наполнило раздел
источников авторами, которых владелец не выбирал и происхождение которых было трудно
понять до открытия нескольких технических экранов.

## Решение

1. Stable coauthor identity из observations вручную подключённого автора становится
   производным кандидатом, а не автоматически материализованным Author.
2. Кандидаты выводятся отдельным разделом `/library/authors`; canonical список
   авторов и список кандидатов не смешиваются.
3. Переход по кандидату открывает `/library/authors/candidates/{slug}` с focused
   provenance graph: исходные авторы, книги-evidence и внешний профиль.
4. Только CSRF-защищённое явное подтверждение создаёт/reuses canonical Author,
   non-preferred author SourceLink, SourceEndpoint и enabled WatchRule и добавляет
   принятого автора к подтверждённым canonical works.
5. Принятый кандидат остаётся дочерним non-preferred source и сам не расширяет
   discovery graph. Новые кандидаты строятся только из preferred roots, вручную
   подключённых с карточки canonical автора.
6. Кандидаты — read model из validated `SourceObservation.raw.authors`; отдельная
   таблица и миграция не требуются. Уже созданные прежним механизмом авторы и
   источники автоматически не удаляются и не переписываются.

## Последствия

- Polling автора продолжает сохранять полные observations и series reconciliation,
  но больше не создаёт неизвестных авторов и правила опроса без решения владельца.
- Владелец видит причину появления до принятия: кто обнаружил профиль и через какие
  книги; подложный slug нельзя принять, потому что POST повторно проверяет owner-scoped
  derived candidate.
- Старые auto-created источники остаются обратимо управляемыми в текущем UI. Их
  массовая очистка — отдельная явная операция с предварительным аудитом.
- Пункт 4 ADR-0025 о немедленном auto-create superseded этим решением; bounded
  discovery сохраняется, но теперь заканчивается review boundary.
