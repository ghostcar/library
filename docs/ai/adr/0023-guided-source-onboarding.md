# ADR-0023: Guided catalog-first source onboarding

Статус: accepted  
Дата: 2026-08-31

## Контекст

Модель `SourceEndpoint` → `SourceLink` → `WatchRule` позволяет описать несколько
источников метаданных и файлов, но её технический UI требовал от владельца вручную
создавать и связывать все три сущности. После импорта книги ожидаемый пользовательский
поток начинается с уже существующей карточки автора или цикла.

## Решение

1. Карточка автора принимает публичную страницу Author.Today одной операцией.
   Сервер нормализует URL и атомарно создаёт или переиспользует endpoint, прямую
   preferred metadata-связь автора и включённое правило наблюдения, назначенное
   на немедленный фоновый опрос.
2. Серии извлекаются из сохранённых наблюдений страницы автора. UI группирует их
   как кандидатов и показывает существующую карточку, если название уже известно.
3. Подтверждение кандидата создаёт или переиспользует каноническую серию, связывает
   её с обнаруженной страницей источника и backfill-ит `series_id` наблюдений.
4. Сервер не доверяет названию или URL из формы: серия принимается только при
   совпадении с наблюдением выбранного endpoint, а внешний URL берётся из самого
   наблюдения.
5. Низкоуровневый экран источников остаётся для диагностики и нестандартных
   конфигураций, но не является основным продуктовым сценарием.

## Последствия

- Пользователь начинает с карточки каталога и не работает с UUID, endpoint или
  watch rule вручную.
- Первый результат появляется после фонового опроса worker; карточка явно показывает
  состояние до первой проверки и последнюю ошибку.
- Карточка принятой серии показывает дедуплицированное сопоставление книг источника
  с локальным каталогом: есть, отсутствует, неоднозначно. Будущие source works
  получают `series_id` по точному owner-scoped названию серии, даже если canonical
  work пока отсутствует.
- Для отсутствующих и неоднозначных source works владелец выбирает существующую
  книгу из каталога либо отдельно подтверждает создание карточки. Reconciliation
  связывает все ревизии, series membership и direct work source link; title-only
  evidence не создаёт книгу автоматически.
- Этот guided UX пока реализован для профиля Author.Today; остальные разрешённые
  website adapters должны подключаться через тот же продуктовый контракт.
