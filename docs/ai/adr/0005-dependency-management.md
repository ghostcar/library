# ADR-0005: Управление зависимостями — venv на системном Python, pyproject.toml, pip

Статус: accepted
Дата: 2026-08-25

## Контекст

Промпт предлагает uv + pyproject.toml. На VPS uv отсутствует; пользователь выбрал обычный venv на актуальном системном Python 3.13.

## Решение

- Зависимости объявляются в `pyproject.toml` (PEP 621), включая optional group `dev`.
- Виртуальное окружение: `python3 -m venv .venv`, установка `pip install -e ".[dev]"`.
- Воспроизводимость: pip `--require-hashes` не используем на этом этапе; версии основных зависимостей фиксируются нижними границами в pyproject и фактически закрепляются в Dockerfile. Lock-файл (requirements.lock через pip-compile или переход на uv) — открытый вопрос, см. OPEN_QUESTIONS.md.

## Последствия

- Скрипты dev/test/lint используют `.venv/bin/` напрямую.
- При росте команды/сложности — пересмотреть в сторону uv (одна команда миграции).
