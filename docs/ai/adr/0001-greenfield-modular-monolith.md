# ADR-0001: Greenfield — модульный монолит, ядро портала + модуль library

Статус: accepted
Дата: 2026-08-25

## Контекст

Репозиторий `github.com/ghostcar/library` пуст (проверено через `gh repo view`: `isEmpty: true`). Локальный `~/library` не был git-репозиторием. Мастер-промпт §0: если репозиторий пустой — создать минимальное ядро модульного макропортала и библиотеку как первый доменный модуль.

## Решение

1. Greenfield-сценарий: создаём ядро макропортала (`src/portal/core`) и модуль `library` (`src/portal/modules/library`) в одном репозитории.
2. Архитектурный стиль — модульный монолит со слоями domain/application/infrastructure/presentation/adapters (§4.1).
3. Межмодульное взаимодействие — через application ports и события, не через ORM-модели другого модуля.
4. Все пользовательские данные с `owner_id` с первого дня, несмотря на однопользовательский режим.

## Последствия

- Нет параллельных систем аутентификации/настроек — они появятся в core и будут переиспользоваться.
- При появлении других модулей макропортала они встраиваются через module_registry.
