# ADR-0003: Разработка на целевой VPS, изоляция от соседних сервисов

Статус: accepted
Дата: 2026-08-25

## Контекст

Разработка ведётся прямо на целевой тестовой VPS. На той же машине уже работают: tracker (docker, 127.0.0.1:8000 + tracker-db на 127.0.0.1:5432), OmniRoute (127.0.0.1:20128), cypht (post.gorbunovr.ru), pl-multisession-pg (127.0.0.1:55433). Хостовый nginx (80/443) обслуживает домены через Cloudflare (origin cert). DNS для `library.gorbunovr.ru` отсутствует. Passwordless sudo нет.

## Решение

1. Dev-стек library: web на `127.0.0.1:8001`, worker — без сетевых портов, PostgreSQL-контейнер **без публикации порта на хост** (доступ только из compose-сети).
2. Volumes с префиксом `library_`.
3. Конфиг nginx для `library.gorbunovr.ru` хранится в `deploy/nginx/library.conf` и применяется пользователем вручную (нужен sudo) после добавления DNS-записи.
4. TLS — через Cloudflare + существующий origin cert (тот же механизм, что у tracker).
5. Никаких изменений в чужих compose-проектах и контейнерах.

## Последствия

- Локальная разработка и тестовый контур — одна и та же машина; риск воздействия на соседей минимизирован привязкой к 127.0.0.1 и отсутствием публикации портов.
- Деплой Phase 9 сведётся к: DNS-запись (пользователь), копирование nginx-конфига (пользователь), docker compose up (скрипт).
