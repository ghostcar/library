# ADR-0020: Litnet — автоматическое HTML-наблюдение не включать

Статус: accepted  
Дата: 2026-08-28

## Контекст

Для закрытия `OPEN_QUESTIONS#10` проверены актуальные публично доступные
`robots.txt`, пользовательское соглашение и индексируемая форма публичной
страницы автора Litnet. Технически страницы автора и списка книг существуют,
но пользовательское соглашение прямо запрещает использовать автоматизированные
программы для сбора информации на сайте.

## Решение

Не реализовывать и не включать Litnet HTML adapter. Не выполнять дальнейшие
автоматические запросы к публичным страницам Litnet, не использовать браузерную
автоматизацию, cookies, авторизацию, внутренние/недокументированные API или
обход технических ограничений.

Изменить это решение можно только при появлении официального API/RSS с
подходящими условиями либо при явном письменном разрешении Litnet на такой
персональный metadata-only polling. Тогда требуется новое исследование,
fixtures, versioned selectors, rate limit и отдельный ADR.

## Последствия

- `litnet` остаётся disabled в реестре источников; UI и worker не создают для
  него правила или jobs.
- Полнота мониторинга уступает соблюдению условий платформы.
