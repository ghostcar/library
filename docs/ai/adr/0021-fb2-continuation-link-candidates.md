# ADR-0021: FB2 continuation links are review candidates, not catalog records

Статус: accepted  
Дата: 2026-08-28

## Решение

Из локально импортированных FB2 извлекаются только public HTTP(S)-ссылки,
у которых ближайший текст содержит маркер продолжения/новой книги. Сохраняются
URL и ограниченный контекст как owner-scoped candidate, привязанный к исходному
asset/work. Оригинал и литературный текст не меняются.

Владелец вручную запускает проверку одной ссылки. Она разрешена только для
public HTTPS host, после успешной проверки `robots.txt`; redirects, private
network targets, non-HTML, oversized/error responses и robots denial fail closed.
Из страницы читается только `og:title` либо HTML title. Название сопоставляется
с каталогом точно по нормализованному title; отсутствие единственного совпадения
остаётся кандидатом на новую книгу. Ни work, ни source endpoint, ни файл не
создаются автоматически.

## Последствия

- Функция не является crawler'ом и не читает главы/не скачивает файлы.
- Сайты с запретом robots/непроверяемыми правилами остаются blocked в UI.
- Эвристика намеренно может пропустить неявную ссылку; false-positive не меняет
  каталог и требует ручного решения.
