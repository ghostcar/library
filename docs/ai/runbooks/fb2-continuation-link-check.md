# FB2: проверка ссылки на продолжение

Функция появляется после развёртывания migration `0013` и коммита `84e8bed`.
В разделе «Импорт» владелец вручную нажимает «Проверить заголовок» у кандидата,
который был извлечён из уже локального FB2.

## Последовательность и границы

1. Локальный extractor сохраняет только `http(s)` ссылку с ближайшим контекстом
   о продолжении/новой книге. Он не меняет FB2 и не делает сетевых запросов.
2. Кнопка принимает только HTTPS URL без credentials; DNS должен вернуть только
   public IP. Loopback, private, link-local и другие non-global адреса отклоняются.
3. Запрашивается ровно `https://<host>/robots.txt` с User-Agent
   `ghostcar-library/0.1 (personal link review)`. При `200` учитываются
   applicable `User-agent: ghostcar-library`/`*` и `Disallow`; `404` означает
   отсутствие robots. Redirect, иной статус или недоступность fail closed.
4. Затем выполняется один GET исходного URL: без redirects, только `200 text/html`,
   до 512 KiB, timeout 10 секунд. Берётся `og:title`, иначе `<title>`.
5. Главы, текст книги, изображения, файлы, cookies, учётные данные, API и retries
   не используются. Exact title match связывается с каталогом; иначе — кандидат.

## Зачем robots.txt

Ручная кнопка запускает HTTP-клиент сервера и поэтому остаётся
автоматизированным запросом. Проверка robots — минимальная техническая граница,
не позволяющая обходить опубликованное ограничение. Она не crawler и не применяется
к импорту FB2 или к другим частям портала.

Если кандидат blocked, не ослаблять код: открыть ссылку вручную в браузере либо
получить официальный API/RSS/разрешение.
